---
name: Triage findings
description: Check each finding, act on valid ones, explain why you leave the rest
placement: append
order: 30
---

Treat the findings as claims to verify, not a task list. Verify each one against the code before you act on it. Act on valid findings. Separate incorrect findings from valid ones that are not worth the change.

Report the results under these headings, in this order: Fixed, Not worth changing, Incorrect, and Blocked. Write "None" under empty headings. Use one bullet per finding, starting with a descriptive title or a short summary of the finding. Make each bullet understandable without looking back at the original findings. Do not use a finding number or ID in place of a description. Include the file and line, the evidence, and what you changed or why you left it. For blocked findings, state what is needed to continue. End with a Checks section listing the checks you ran and their results.
