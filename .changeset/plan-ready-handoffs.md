Check that a plan is ready before an implementation handoff or a worktree for one. The handoff skill
defines ready: the goal, scope, acceptance criteria, and every choice that changes the result are in
the ticket or approved by the user. When something is open, the sender asks its user and sends
nothing. Each implementation handoff carries a plan status, and the receiver asks its user before
editing if the status lists open questions. The worktree skill creates a worktree only when the user
asks for one.
