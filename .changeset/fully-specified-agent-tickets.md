Write fully specified agent tickets when a slice starts. The manager decides signatures, data
shapes, error cases, and the helper to copy before drafting, and writes them into each ticket. Each
part that still needs judgment gets its own earlier ticket. Scouts also report design choices a
ticket leaves open. The agent-ticket template replaces `## First test` with `## Test cases`, a list
of named tests with input and expected result.
