Add the pr skill. It creates or updates the GitHub pull request for the current branch. It commits
the task's changes and release notes, removes added comments that break the coding rules, and reuses
or runs a fast code review and the required checks. It previews the title, body, base, and draft
status, and pushes or publishes only after approval. After publishing, it offers to request bot
reviews, such as Codex.
