`draft_review` shows files in tuicr in the order of the `paths` you pass. Staged names now start
with order numbers, such as `01-pr-run-5ASmpd/1-title.md`, so the PR drafts of a stack no longer
show in random order. Comments and edits still come back under their `.tau` paths, and reviews
opened before this change still collect.
